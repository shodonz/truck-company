# Samarkand Restaurant — сайт

Узбекская и таджикская кухня, 1842 S Parker Rd, Denver, CO 80231.

Статический сайт: чистые HTML + CSS + JS. Без сборки, без npm, без фреймворков.
Открывается как есть, грузится меньше секунды, ставится на любой хостинг.

---

## Как поменять цены (главное)

Открой **`data/menu.js`**, найди блюдо, поменяй число в `price`. Всё.

```js
{
  id: "uzbek-plov",
  en: "Uzbek Plov",
  ru: "Плов",
  desc: "The most traditional Uzbek entree...",
  price: 16,        // ← меняешь только это
  img: "uzbek-plov.jpg",
  tags: ["signature"]
}
```

* `price: null` — цена не подтверждена. Сайт покажет «Ask us / Уточняйте»
  вместо выдуманной суммы. Как только узнаешь цену — впиши число.
* `tags` — `"signature"` (хит, попадает на главную), `"veg"`, `"spicy"`.
* `unit: "pc"` — цена за штуку.
* `variants` — несколько размеров (например, компот: стакан / кувшин).
* `verify: true` — пометка «надо перепроверить у клиента», на сайт не выводится.

Категории меню — это верхнеуровневые объекты в том же файле. Порядок категорий
на сайте = порядок в массиве.

## Как поменять контакты, часы, ссылки

Всё в **`data/site.js`**: телефон, WhatsApp, e-mail, адрес, часы работы по дням,
ссылки на DoorDash / Uber Eats / соцсети, блок преимуществ.

**Часы работы** — понедельник выходной (`open: null`), остальные дни 12:00–22:00.
Плашка «Открыто сейчас / Закрыто» считается по времени Денвера автоматически,
независимо от того, откуда зашёл гость.

**Преимущества** (`amenities`) — у четырёх пунктов стоит `enabled: false`:
парковка, Wi-Fi, детское меню, оплата картой. Это не забытые пункты — они
намеренно выключены, пока клиент не подтвердит факты. Подтвердил → поставь
`enabled: true`, и блок появится на сайте.

**Отзывы** (`reviews`) — пустой массив, секция отзывов скрыта. Добавь объекты
`{ author, rating, text, source }` — секция включится сама.

## Как поменять тексты

**`data/i18n.js`** — все тексты интерфейса на двух языках. В HTML лежат только
ключи (`data-i18n="hero.title"`). Описания блюд живут в `menu.js` и остаются
только на английском — так требует ТЗ.

## Фотографии

Фото качаются с Google Drive клиента одной командой:

```bash
bash scripts/fetch-images.sh
```

Скрипт разложит их в `assets/img/dishes/` под нужными именами и в конце
напечатает список фото, которых на Drive нет.

**Если фото нет — сайт не ломается**: вместо картинки показывается аккуратный
орнаментальный плейсхолдер в тон палитре.

Что нужно доложить руками:
* `assets/img/hero.jpg` — главное фото шапки (качается скриптом из `Hero.jpg`)
* `assets/img/story-registan.jpg` — фото Регистана для страницы «О нас»
* `assets/img/interior/hall-1.jpg`, `hall-2.jpg` — зал
* фото для: beef-kebab, salmon-kebab, lamb-chops, kebab-meal, rice,
  fried-potatoes, french-fries, paklava и напитков

### Видео в шапке
Решили не снимать. Если появится — положи `assets/video/hero.mp4` и в
`data/site.js` поставь `heroVideo: "assets/video/hero.mp4"`. Фото останется
как poster, на мобильных видео не грузится.

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Просто дважды кликнуть по `index.html` тоже сработает — данные подключены как
обычные JS-файлы, а не через `fetch`, поэтому `file://` не мешает.

## Публикация

Любой статический хостинг. Рекомендую Cloudflare Pages (бесплатно, HTTPS,
CDN, свой домен):

1. Залить репозиторий на GitHub.
2. Cloudflare Pages → Create project → выбрать репозиторий.
3. Build command — оставить пустым, Output directory — `/`.
4. Custom domain → подключить купленный домен.

После покупки домена вписать его в:
* `data/site.js` → `canonical`
* `robots.txt`, `sitemap.xml`
* `<link rel="canonical">` и `og:*` в трёх HTML-файлах

```
index.html          Главная
menu.html           Полное меню
about.html          О нас

data/site.js        Контакты, часы, ссылки, преимущества    ← правишь ты
data/menu.js        Меню и цены                             ← правишь ты
data/i18n.js        Все тексты RU/EN                        ← правишь ты

assets/css/style.css
assets/js/app.js    Вся логика: язык, часы, меню, заказ, модалка
assets/img/         Фото
scripts/fetch-images.sh
robots.txt  sitemap.xml
```

## Что уже сделано

* Мультиязычность RU/EN, переключатель в шапке, выбор запоминается
* Меню из структурированных данных, поиск, фильтры по категориям и тегам
* Конструктор заказа: добавляешь блюда → уходит в WhatsApp готовым текстом
* 4 сценария WhatsApp: самовывоз, доставка, бронь стола, большая компания
* Кнопки DoorDash и Uber Eats (Grubhub и Seamless убраны — рабочих ссылок нет)
* Schema.org Restaurant + Menu + OpeningHours (генерируется из тех же данных)
* Mobile-first, без горизонтального скролла, `prefers-reduced-motion`
* Проверено в Chromium на 390px и 1440px, ошибок JS нет
